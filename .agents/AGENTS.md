# UI Rules

This project follows the UI UX Pro Max Skill.

Always design using:

- Modern SaaS
- Large whitespace
- Consistent spacing
- Professional typography
- Accessible colors
- Responsive design
- Tailwind CSS best practices
- Beautiful hover animations
- Rounded corners
- Subtle shadows

Never create outdated looking interfaces.

When in doubt,
prefer premium Apple / Linear / Stripe style UI.
